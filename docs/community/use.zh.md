## 浏览会话

从侧栏打开已有会话。“对话”显示消息，“轨迹”显示执行历史。手机标题单独占一行，避免长标题占满任务栏空间。使用现有侧栏控件返回会话列表。

<a id="native-session-tools"></a>

## 原生会话工具

| 入口 | 含义 | 查看方式 |
| --- | --- | --- |
| 子智能体 | 直接子会话，包含已结束子会话，不是运行任务总数 | 打开原生目录，查看状态并进入子会话 |
| 智能体团队 | 已启用的实验性团队原生面板 | 查看成员和共享任务板，不另外创建重复任务板 |
| 后台任务 | 当前会话的原生 Job | 打开原列表并查看输出；活动数量包括 running 和 stopping |
| 自动化任务 | 定时跟进和提醒，与 Jobs 不同 | 原生条件满足时打开现有目录 |

已完成、失败或终止的 Job 不计入活动任务。空目录遵循上游功能的显示规则。数量变化不代表社区 UI 启动、停止或重新创建了任务。

## 插件与模式

“插件”菜单集中第三方 Header 扩展，原生会话工具保留独立入口。只有安装并注册 RAM 插件时才会出现监控项；社区布局不以安装 RAM 为前提。

<details>
<summary>查看插件面板</summary>

演示注册了两个测试扩展，不展示或验证 RAM 遥测。

![包含测试扩展的展开插件面板](images/plugins-expanded.png)

</details>

当前所选模式不再常驻任务栏。配置模式仍使用原有新会话或设置入口，隐藏标签不改变已有会话的 composition。

<a id="read-and-compose"></a>

## 阅读与输入

对话支持段落、列表、行内代码和代码块。长代码保留格式及独立横向滚动，超长路径不应撑宽整个页面。

输入区保留附件、权限、模型和发送控件，权限与模型菜单继续使用原有行为。手机打开或关闭键盘后，请检查多行输入及发送按钮。视觉紧凑的图标仍需具有可用的触摸区域。

<a id="connection-and-recovery"></a>

## 连接与恢复

普通导航和刷新继续使用 DSH 现有会话与流恢复机制。仅恢复一个状态图标不能证明所有输出均已还原。原生 Jobs 是进程内存中的执行记录；浏览器重连不保证 Host 进程重启后的任务恢复。

凭据失效时，使用当前服务原有登录或配对流程。不要仅为让运行任务重新出现而重发消息。排查重复执行时，可在私人诊断记录中保存会话与任务标识。
